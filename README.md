# 📚 Kitap Takip Sistemi

## Proje Hakkında
Kitap Takip Sistemi, kitap bilgilerini düzenlemek ve takip etmek amacıyla geliştirilmiş bir web projesidir.

## Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Projenin Amacı
Web geliştirme becerilerimi geliştirmek ve öğrendiğim teknolojileri uygulamalı bir projede kullanmak amacıyla hazırlanmıştır.

## Teknik Özellikler
- Tarayıcı tabanlı çalışma
- LocalStorage ile verileri tarayıcıda saklama
- HTML, CSS ve JavaScript kullanımı
